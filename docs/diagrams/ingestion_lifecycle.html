Dual-Write Immunity

  • • FastAPI commits document version and outbox record in a single ACID transaction
  • • Eliminates orphaned files and distributed state drift on broker crashes
  • • Fast HTTP 202 Accepted response decouples client from heavy ingestion latency

FOR UPDATE SKIP LOCKED Dispatch

  • • Background daemon polls private.job_dispatch_outbox with concurrency-safe locking
  • • Multiple dispatcher processes run concurrently without deadlocks or row contention
  • • Events marked dispatched_at only after Redis acknowledges message receipt

Zero-Cost Local Embeddings

  • • Dramatiq workers execute PyPDF/Markdown normalization and semantic chunking
  • • FastEmbed runs local BAAI/bge-small-en-v1.5 ONNX model on CPU (384 dimensions)
  • • PostgreSQL updates both HNSW vector cosine and GIN BM25 tsvector indexes
